# Documentos de Cumplimiento — Inmobiliaria JMK

Carpeta lista para publicarse en GitHub Pages. Estructura:

```
documentos-cumplimiento/
├── index.html                  ← página índice (con logo JMK), enlaza a ambos documentos
├── logo_jmk_oficial.png
├── codigo-etica/
│   ├── index.html               ← Código de Ética v1 (con logo)
│   ├── logo_jmk_oficial.png
│   └── codigo-etica-jmk-v1.pdf
└── manual-cumplimiento/
    ├── index.html               ← Manual de Cumplimiento SUGEF v1 (con logo)
    ├── logo_jmk_oficial.png
    └── manual-cumplimiento-sugef-jmk-v1.pdf
```

## Cómo subirla
1. Copia la carpeta `documentos-cumplimiento/` completa a la raíz del repo de GitHub Pages de la agencia (por ejemplo, junto a `jmk-dossiers`), o a un repo nuevo dedicado.
2. La página índice quedará disponible en:
   `https://<usuario-o-org>.github.io/<repo>/documentos-cumplimiento/`
3. Si prefieres que el índice sea la portada del sitio, mueve el contenido de `documentos-cumplimiento/` a la raíz del repo.

## Convención para nuevos documentos
A partir de ahora, cada documento de cumplimiento (nuevo o actualizado) debe:
- Incluir el logo `logo_jmk_oficial.png` en su propio encabezado.
- Agregarse como una nueva tarjeta en `index.html` de esta carpeta, con su logo, fecha de emisión y enlaces a la página y al PDF — de forma que el índice general siempre muestre el logo de Inmobiliaria JMK junto con todos los documentos disponibles.
